# Проверки 5.2

- Хранение данных
  Данные хранятся в localStorage под ключом favorites в виде JSON-строки с массивом числовых ID товаров, например "[1,3,5]".
  Функции изменения данных
  loadFavorites() — загружает ID из localStorage с защитой от мусора, вызывается при загрузке страницы.
  saveFavorites() — сериализует массив favoriteIds и сохраняет в localStorage, вызывается внутри toggleFavorite().
  toggleFavorite(id) — добавляет или удаляет товар из избранного, вызывает saveFavorites(), срабатывает при клике на кнопку ♥.
- Функции вывода на страницу
  renderProducts() — отрисовывает карточки товаров, добавляет модификатор card--favorite и переключает aria-pressed, вызывается при загрузке, после toggleFavorite() и при изменении фильтра.
  renderFavoritesCounter() — обновляет счётчик «Избранное: N» в шапке, вызывается при загрузке и после toggleFavorite().
- Обрабатываемые события
  click на .card**favorite-btn через делегирование на .card-list — вызывает toggleFavorite(id).
  click на .card**btn через делегирование на .card-list — логирует ID товара (заготовка для корзины).
  change на #only-favorites-toggle — меняет флаг showOnlyFavorites и вызывает renderProducts().
- Проверенные крайние случаи
  Мусор в массиве [1, "abc", null] — нечисла отфильтрованы, остаётся только валидный ID. Результат: ✅ пройдено.
  Оборванная строка JSON '{"ids": [1,' — try/catch ловит SyntaxError, возвращается пустой массив. Результат: ✅ пройдено.
  Не массив '123' — Array.isArray() возвращает false, возвращается пустой массив. Результат: ✅ пройдено.
  Несуществующий ID [1, 999] — ID, которых нет в products, отфильтрованы. Результат: ✅ пройдено.
  Пустой массив '[]' — счётчик показывает «Избранное: 0». Результат: ✅ пройдено.
  Нет данных в localStorage — raw === null, возвращается пустой массив. Результат: ✅ пройдено.
  Фильтр «Только избранное» при пустом избранном — показывается сообщение «В избранном нет товаров». Результат: ✅ пройдено.
  Двойной клик по ♥ — состояние корректно переключается (добавил → удалил). Результат: ✅ пройдено.
- Защита от мусора
  Функция loadFavorites() последовательно проверяет: отсутствие данных, корректность JSON, что значение является массивом, что каждый элемент — целое число, и что товар с таким ID реально есть в массиве products. Любая ошибка приводит к возврату пустого массива, поэтому страница всегда открывается без сбоев.
