# Причина мигания

- Браузер читает HTML сверху вниз. Когда он доходит до тега `<body>`, он сразу начинает его отрисовывать, используя стили по умолчанию (`:root`).
- Внешний файл `script.js`, который проверяет `localStorage` и добавляет класс `page--dark`, загружается и выполняется асинхронно или с задержкой (после парсинга HTML).
- В этот короткий промежуток времени страница уже отрисована со светлой темой, и только потом JS "перекрашивает" её.

- Чек-лист выполнения:

- Кнопка имеет `aria-pressed`.
- Тема задается через модификатор `.page--dark` на `<body class="page">`.
- В CSS переопределяются **только** переменные, блоки не тронуты.
- Выбор сохраняется в `localStorage`.
- Если в `localStorage` записать `'blue'`, строгое сравнение `=== 'dark'` вернет `false`, и страница откроется в светлой теме без ошибок.
