# Система «Поиск по каталогу»

- Добавленные функции и их назначение
  Переменная состояния searchQuery хранит текущую строку поиска, введённую пользователем. Обработчик события input на поле #search-input обновляет searchQuery на каждое изменение значения и вызывает renderProducts(), обеспечивая фильтрацию в реальном времени. Обработчик события keydown отслеживает нажатие клавиши Escape: при срабатывании очищает поле ввода, сбрасывает searchQuery в пустую строку, перерисовывает каталог и убирает фокус с поля через blur(). Функция renderProducts() была расширена: теперь она применяет два фильтра последовательно — сначала фильтр «Только избранное» (если включён переключатель), затем фильтр поиска по подстроке в названии товара. Логика пустого состояния также расширена и теперь выводит одно из трёх сообщений в зависимости от контекста: «Ничего не найдено по запросу «...»», если есть поисковый запрос и результатов нет; «В избранном нет товаров», если включён фильтр избранного и избранных товаров нет; «Товаров нет», если товаров нет в принципе. Запрос вставляется в сообщение через textContent для защиты от XSS-атак.
- Проверенные крайние случаи
  Поиск без учёта регистра — ввод «МЫШЬ», «мышь» и «Мышь» даёт одинаковый результат, находятся одни и те же товары. Результат: ✅ пройдено.
  Пробелы по краям запроса — ввод « Мышь » обрабатывается так же, как «Мышь», пробелы игнорируются методом trim(). Результат: ✅ пройдено.
  Поиск вместе с фильтром «Только избранное» — при включённом фильтре и введённом запросе показываются только избранные товары, подходящие под поиск. Результат: ✅ пройдено.
  Ничего не найдено — при вводе несуществующего названия (например, «xyz123») отображается сообщение «Ничего не найдено по запросу «xyz123»», список карточек скрыт. Результат: ✅ пройдено.
  Escape очищает поиск — после нажатия Escape поле ввода становится пустым, searchQuery сбрасывается, каталог возвращается к полному списку, фокус уходит с поля. Результат: ✅ пройдено.
  Пустой запрос после очистки — если пользователь стёр весь текст вручную, фильтр поиска отключается, показываются все товары (с учётом фильтра избранного, если он включён). Результат: ✅ пройдено.
  Защита от XSS в сообщении — если в поле поиска ввести HTML-теги или скрипт (например, <img src=x onerror=alert(1)>), они отображаются как обычный текст благодаря textContent, выполнение кода не происходит. Результат: ✅ пройдено.
  Счётчик обновляется корректно — при фильтрации текст «Показано: N из 8» отражает количество найденных товаров, а не общее число. Результат: ✅ пройдено.
  Поиск по частичному совпадению — ввод «но» находит товары «Ноутбук», «Наушники» и другие, содержащие подстроку «но» в названии. Результат: ✅ пройдено.
  Сброс поиска при переключении фильтра — если очистить поиск и переключить «Только избранное», каталог корректно перерисовывается без артефактов. Результат: ✅ пройдено.
