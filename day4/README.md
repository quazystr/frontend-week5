# Заметки day4

- task-4.3: Обработчики вешаются только на те кнопки, которые существуют в момент вызова renderTags().
  Когда мы добавляем новый тег, вызывается renderTags(), который пересоздаёт весь список. Старые кнопки удаляются из DOM и создаются новые. Но новые кнопки не имеют обработчиков, потому что мы их не повесили.
