## Результаты проверок

- Пустая задача и задача из пробелов: не добавляются. Появляется ошибка «Введите название задачи», фокус остается в поле ввода. ✅ Пройдено.
- Длина названия: задача ровно на 100 символов добавляется и не ломает верстку. Попытка добавить 101 символ блокируется, выводится соответствующая ошибка. ✅ Пройдено.
- XSS-инъекция: при вводе названия <img src=x onerror=alert(1)> код выводится на странице как обычный безопасный текст, всплывающее окно alert не появляется. ✅ Пройдено (благодаря использованию textContent).
- Двойной клик по кнопке «Добавить»: создается только одна задача, дубликаты не появляются. ✅ Пройдено (кнопка получает атрибут disabled на время обработки события).
- Сохранение состояния: после перезагрузки страницы (F5) все добавленные задачи, их статусы (выполнено/активно) и выбранный фильтр восстанавливаются. ✅ Пройдено.
- Мусор в localStorage: при ручной порче данных в хранилище (например, оборванная JSON-строка или объект без поля title) приложение не падает. Отображается пустой список, в консоли нет ошибок уровня Error (только безопасное предупреждение console.warn). ✅ Пройдено.
- Адаптивность (360 px): при сужении окна браузера до 360 пикселей горизонтальная прокрутка отсутствует, элементы формы и списка корректно сжимаются и не вылезают за границы экрана. ✅ Пройдено.
- Управление с клавиатуры (a11y): навигация клавишей Tab проходит все интерактивные элементы в логическом порядке. Enter отправляет форму, Пробел переключает чекбоксы. Видимый фокус (outline) четко отображается на всех элементах, включая поля с ошибкой валидации. ✅ Пройдено.
- Валидация W3C: при проверке развернутой страницы через validator.w3.org ошибок валидации HTML-разметки не найдено. ✅ Пройдено.
- Консоль разработчика: при любых действиях (добавление, удаление, фильтрация, очистка, перезагрузка) в консоли браузера отсутствуют сообщения об ошибках (Uncaught Error, TypeError и т.д.). ✅ Пройдено.
