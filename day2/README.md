# Заметки day2

- task-2.3: если мы не будем использовать копию массива с методом sort, то изменится и оригинал массива, и соотвественно сломается логика. Если убрать копирование, будет ссылка на тот же самый, но перетасованный массив.

- task-2.5:
- const a = { title: 'Мышь', tags: ['input'] }; // объект с двумя элементами
- const b = a; // ссылка на объект а
- const c = { ...a }; // копия объекта а
- b.title = 'Клавиатура'; // изменение тайтла в объекте а
- c.tags.push('usb'); // изменение в копии объекта а
- console.log(a.title, a.tags.length); // "Клавиатура", 1.
  P.S. Узнал что через копию массива тоже меняется основной объект
