# Заметки day1

- в task-1.1 необычными оказались typeof "emptyValue = null;" и массив "courses", так как они выдали тип object. В случае с null это историческая ошибка, на самом деле это примитивный тип, а массив просто не является отдельным примитивным типом

- task-1.2 прогноз: "51", [], false, 42, 4, true, "10", false, 42, NaN, true, NaN.
- Результат: "51", ,false, 42, 4, true, 10, false, 42, 2, true, NaN.
- Ошибки: в 10 - записал строкой, 2 - записал NaN, true считается за 1

- task-1.3: null и "" дают 0 потому что при приведении к числу используется неявное привдедение типов, функцию исправил на строгое сравнение null и ""
